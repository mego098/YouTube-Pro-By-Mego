# YouTube Pro - By Mego 🔥
### أداة تحميل فيديوهات يوتيوب بكل الجودات - Python 3.8

![Python](https://img.shields.io/badge/Python-3.8-blue) ![Version](https://img.shields.io/badge/Version-1.0-yellow) ![Author](https://img.shields.io/badge/Author-Mego-red)

أداة سريعة وخفيفة لتحميل فيديوهات يوتيوب بأي جودة (360p - 4K) باستخدام مكتبة PytubeFix.

## المميزات ✨
- تحميل بأي جودة متاحة للفيديو
- واجهة جرافيك سهلة جدا
- يشتغل على Python 3.8 بدون مشاكل yt-dlp
- بيحمل الصوت والفيديو مدمجين

## طريقة التشغيل 🚀
```bash
pip install pytubefix
python youtube_pro_by_mego.py
```

## تحويل لـ EXE 💻
```bash
pyinstaller --onefile --noconsole --name "YouTube-Pro-By-Mego" youtube_pro_by_mego.py
```
